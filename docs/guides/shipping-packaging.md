# Shipping & Packaging Standards

## Packaging Architecture

PeptideSourceHub employs a multi-layer packaging system designed to maintain product integrity from dispatch through delivery. The architecture comprises three protective layers:

| Layer | Component | Function |
|---|---|---|
| **Primary** | Amber borosilicate glass vial, PTFE-lined cap, crimp-sealed | Product containment; light and moisture barrier |
| **Secondary** | Vacuum-sealed multi-layer moisture-barrier pouch with desiccant | Humidity control; physical protection; tamper evidence |
| **Tertiary** | Corrugated cardboard outer carton with cushioning inserts | Impact protection; thermal insulation; discreet exterior |

## Primary Packaging: Vials

| Specification | Detail |
|---|---|
| **Material** | USP Type I borosilicate glass (amber) |
| **Cap & Septum** | Aluminum crimp cap with PTFE-lined butyl rubber septum |
| **Sizes Available** | 2 mL, 5 mL, 10 mL (standard); custom sizes per project |
| **Fill Volume** | Lyophilized powder; headspace flushed with dry nitrogen |
| **Labeling** | Tamper-evident label with product name, CAS number, batch number, net peptide content, storage condition, expiry date, and "FOR RESEARCH USE ONLY" statement |

## Secondary Packaging: Moisture-Barrier Pouch

Each vial is individually sealed in a multi-layer vacuum pouch:

| Layer | Material | Function |
|---|---|---|
| **Outer** | Polyethylene terephthalate (PET) | Print surface; abrasion resistance |
| **Middle** | Aluminum foil (9–12 μm) | Moisture and oxygen barrier; light barrier |
| **Inner** | Linear low-density polyethylene (LLDPE) | Heat-seal layer; chemical inertness |

A silica gel desiccant sachet is included in each pouch to maintain <10% relative humidity. Oxygen indicators are available upon request for oxygen-sensitive products.

## Temperature-Controlled Shipping

### Standard Protocol

Lyophilized peptides are stable at ambient temperature for short-duration transit. The default shipping method is ambient with the following requirements:

- Transit time ≤14 days from dispatch to delivery
- Maximum exposure temperature ≤40°C (validated stability data)
- Shipments are routed to avoid weekend warehouse holds

### Cold Chain Protocol (Optional)

For temperature-sensitive products or extended transit routes:

| Component | Detail |
|---|---|
| **Insulated Container** | Expanded polystyrene (EPS) with 30–40 mm wall thickness; or vacuum-insulated panels (VIP) for premium shipments |
| **Coolant** | Phase-change material (PCM) packs conditioned to 2–8°C |
| **Duration** | Validated for 72–120 hours thermal protection (dependent on ambient conditions and container configuration) |
| **Seasonal Adjustments** | Summer months (May–September): increased coolant pack quantity for southern hemisphere destinations; Winter months (November–March): freeze-protection packs added for northern latitude destinations |

### Temperature Data Loggers

| Logger Type | Features | Use Case |
|---|---|---|
| **USB PDF Logger** | Single-use; generates PDF report on USB connection; ±0.5°C accuracy; 16,000-point memory | Standard cold chain verification |
| **Multi-use Logger** | Reusable; configurable sampling interval; NIST-traceable calibration certificate | GLP/GMP-compliant shipments |
| **Real-Time Logger** | Cellular/wireless data transmission; cloud dashboard; geolocation + temperature; customizable alert thresholds | High-value shipments; regulatory audits |

Temperature loggers are available as an add-on service. The USB PDF logger is included by default with cold chain shipments.

## Batch Traceability

Every primary container carries a unique, batch-traceable serial number:

| Identifier | Format | Example |
|---|---|---|
| **Batch Number** | Product code + YYMM + sequential | BPC-2403-042 |
| **Vial Serial Number** | Batch number + vial position | BPC-2403-042-07 |
| **Kit Serial Number** | Kit-level unique identifier | PSH-KT-2403-0815 |

All identifiers are linked to the manufacturing batch record, which includes:

- Raw material lot numbers and supplier COAs
- Synthesis run parameters
- Purification chromatograms
- QC release test results
- Packaging and labeling records
- Environmental monitoring data during production

Batch records are retained for a minimum of 5 years and are accessible upon request for audit purposes.

### Cost Factors

Shipping cost is determined by:

- Dimensional weight (volumetric) vs actual weight (carrier charges the greater)
- Destination zone and service level
- Declared value (insurance surcharge above $5,000)
- Optional services (cold chain, Saturday delivery, temperature logger)

Typical cost ranges for a standard 10-vial kit (approx. 0.5 kg dimensional weight):

| Destination | Express (DHL/FedEx/UPS) | Economy (TNT) |
|---|---|---|
| United States | $35–55 | $25–40 |
| European Union | $30–50 | $20–35 |
| Australia | $35–55 | $25–40 |
| APAC (non-China) | $25–40 | $15–30 |

> Free shipping applies to orders exceeding $800 invoice value.

## Packaging Compliance

| Standard | Application |
|---|---|
| **IATA Dangerous Goods Regulations** | Peptides classified as "Not Restricted" (non-hazardous for air transport); MSDS included |
| **ISTA 3A** | Packaging performance testing for parcel delivery; drop, vibration, and compression testing |
| **WHO Model Guidance for Storage and Transport** | Time-and-temperature-sensitive pharmaceutical products guidance |
| **GDP (Good Distribution Practice)** | EU GDP guidelines followed for temperature-controlled logistics |

## Discreet Packaging Policy

| Element | Policy |
|---|---|
| **Outer Carton** | Plain brown/white corrugated box; no logos, product names, chemical hazard symbols, or company branding |
| **Sender Address** | Returns to a generic logistics address (no "Peptide" or "Biotech" in sender name) |
| **Customs Declaration** | Declared as "Laboratory Research Materials" or "Biochemical Research Sample" with appropriate HS code |
| **Inner Documentation** | All compliant labeling, COA, and MSDS enclosed within the sealed secondary packaging |
| **Tamper Evidence** | Tamper-evident seals on inner containers; outer cartons sealed with reinforced packaging tape |
